# Computer Systems 2B 刷题工具

基于 **PyQt6** 的计算机系统知识巩固与自测桌面应用，支持 AI 出题、中英文切换、自动判题和进度追踪。

## 环境要求

- Python 3.8+
- PyQt6

## 安装与启动

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

或者手动安装：

```bash
pip install PyQt6 requests
```

### 2. 生成示例题目（已内置，可选）

```bash
python seed_data.py
```

> 已预置 13 道示例题目（3 套题目集），覆盖缓存映射、进程状态、CPU 调度、信号量、死锁、GPU、虚拟内存、磁盘调度等专题。

### 3. 启动应用

```bash
python main.py
```

## 功能概览

| 功能 | 说明 |
|---|---|
| 📝 **开始练习** | 从本地题目集中选择，开始答题 |
| 🤖 **AI 生成题目** | 调用 LLM API 自动生成中英双语题目（需在设置中配置 API Key） |
| 📊 **查看进度** | 总览所有答题记录、正确率、各专题统计 |
| ⚙ **设置** | 切换中英文、配置 API Key/模型、导入导出数据 |

## 答题界面

- 提交后**自动判题**（选择题、判断题、配对题、排序题、填空题）
- 每题显示**解析说明**，帮助理解正确选项和干扰项
- 点击 **中/EN** 按钮随时切换题目语言
- 完成后可**重做错题**或**重新练习全部**

## 数据存储

所有数据以 JSON 格式存储在 `data/` 目录：

```
data/
├── question_sets/    # 题目集（按专题组织）
├── questions/        # 单道题目（可跨题集复用）
├── progress/         # 答题记录与进度
└── generated/        # AI 生成的待审查题目
```

## AI 出题配置

1. 打开 **设置 → AI Question Generation**
2. 填入 API Key（支持 Anthropic 或兼容 OpenAI 接口）
3. 选择模型（如 `claude-fable-5`）
4. 回到首页点击 **AI 生成题目**，选择专题和数量即可

> 题目会以 `课程内容.md` 和 `standard.md` 的出题标准为上下文，确保与课程对齐。
